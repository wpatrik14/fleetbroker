# Persona: example fleet node

This is a template - replace this file's content with the actual persona for
the role this node plays (e.g. "GitHub triage node: monitors issues across a
fixed set of repos, never pushes code directly, always relays findings to
the home session for a final decision").

Keep node-specific operational facts here (its role, its scope boundaries,
what it should never do unattended) the way any independently-configured
node keeps its own `CLAUDE.md`.
